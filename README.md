# PHH Property Improvement Plan (MVP samples)

Samples for review by Craig Reid. The staff checklist page is connected to the live n8n workflow.

- `staff-checklist-sample.html` - the staff checklist. Room counts control which bedrooms, bathrooms and living areas show. Preview shows exactly what the owner will get. Owner search (ActiveCampaign, read only) and Generate work: the PDF downloads and a copy is saved to Drive. Nothing is sent to the owner.
- `owner-plan-sample.pdf` - the owner plan as the owner receives it. Only ticked items and areas with content appear.
- `owner-plan-sample.html` - the HTML template the PDF is rendered from (not for review).
- `recommendation-library.csv` - draft improvement library v2 (47 items, revised after Craig's feedback 20 Oct). The live copy is the Google Sheet "PHH Property Improvement Plan - Recommendation Library v2 (DRAFT)".

Design matches the PHH Clean Check housekeeper guide, with PHH blue #0873B5 in place of teal.

Status: draft v0.3, 20 October 2026. The owner PDF sample is a real output from the n8n workflow. Demo due Friday 30 October 2026.
