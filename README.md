# PHH Property Improvement Plan (MVP samples)

Samples for review by Craig Reid. Nothing here is live or connected.

- `staff-checklist-sample.html` - the staff checklist. Room counts control which bedrooms, bathrooms and living areas show. Preview shows exactly what the owner will get.
- `owner-plan-sample.pdf` - the owner plan as the owner receives it. Only ticked items and areas with content appear.
- `owner-plan-sample.html` - the HTML template the PDF is rendered from (not for review).
- `recommendation-library.csv` - draft library (59 items). The live copy is the Google Sheet "PHH Property Improvement Plan - Recommendation Library (DRAFT)".

Design matches the PHH Clean Check housekeeper guide, with PHH blue #0873B5 in place of teal.
